MASROFY - Budget Calculator 

masrofy is a simple budget calculator built with .python

The program allows the user : to

- Calculate a budget .
- expenses Add different types of . 
- amount Track the remaining .
- Display the final result .
- Use the porgram in Arabic or english . 

Technologies : 
- python 
- If / Elif / Else 
- while Loop 
- Try / Except 
- variables and Input 


project Features 

1. Arabic and English language support .
2. Budget calculation .
3. Food, transportation, and other expenses .
4. Additional expense tracking .
5. calculation Remaining budget .
6. Final result display .
7. Invalid input handling .
